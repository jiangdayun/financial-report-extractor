# 白酒行业年报财务数据自动提取工具

从 A 股上市公司 PDF 年报中自动定位财务报表、提取关键字段、计算财务指标，并生成多公司对比表。

在 5 家白酒上市公司 2023 年年报上，25 个字段全部提取正确，10 项计算指标全部通过人工核对。单份处理成本约 0.026 元。

## 在线体验

http://1.12.218.202:8501

需自行上传 PDF 年报（可从巨潮资讯网下载）。

## 解决什么问题

分析师做同业对比时，需要从每份上百页的年报里手工翻找财务数据，再录入 Excel。5 家公司约需 40 分钟，且容易出错。本工具将这个过程压缩到 5 分钟以内，并保留每个数字的原文出处以供核查。

## 处理流程

```
PDF 上传
  ↓
pdfplumber 逐页提取文字
  ↓
关键词定位（三次，分别定位主要会计数据页 / 合并利润表 / 合并资产负债表）
  ↓
DeepSeek API 结构化提取（三次调用，每次只处理一小段相关文字）
  ↓
Python 计算毛利率、资产负债率
  ↓
多公司对比表 + CSV 导出
```

## 提取字段

| 字段 | 数据来源 |
|---|---|
| 营业收入 | 合并利润表「其中：营业收入」 |
| 归母净利润 | 主要会计数据 |
| 扣非净利润 | 主要会计数据 |
| 总资产 | 主要会计数据 |
| 归母净资产 | 主要会计数据 |
| 营业成本 | 合并利润表「其中：营业成本」 |
| 负债合计 | 合并资产负债表期末余额 |

## 计算口径

- 毛利率 =（营业收入 − 营业成本）/ 营业收入
- 资产负债率 = 负债合计 / 资产总计

营业收入采用合并利润表「其中：营业收入」口径，不含利息收入。以贵州茅台 2023 年为例，「营业总收入」1505.60 亿元包含财务公司利息收入 28.67 亿元，而「其中：营业收入」为 1476.94 亿元。利息收入不产生营业成本，计入分母会虚增毛利率，因此采用后者，与主流金融数据终端口径一致。

## 三个关键设计决策

**1. 数据提取交给模型，数值计算交给代码**

大模型做算术会出错，且出错时会给出一个看起来合理的数字，不会报警。所有指标计算在 `metrics.py` 中用 Python 完成，出错会抛异常。

**2. 每个字段返回原文行，每个指标返回算式**

提取结果附带 `raw_line`（模型在原文中找到该数字的完整那一行），计算结果附带 `formula`（代入具体数值的算式）。金融场景下，一个无法追溯来源的数字等于没有价值。

**3. 上下文窗口保持最小**

定位命中后仅取前后各一页交给模型。实测中，扩大窗口会引入母公司报表数据——其字段名与合并报表完全相同但数值不同（茅台母公司资产总计 1715.84 亿元 vs 合并 2726.997 亿元），导致模型抽错。上下文并非越多越好。

## 已知局限

- 仅在白酒行业 5 家公司 2023 年年报上验证，其他行业的报表结构未测试
- 部分年报为双栏排版，pdfplumber 会将同一行数字拆分，依赖 `raw_line` 人工复核兜底
- 依赖关键词定位，若年报使用非常规表述可能命中失败
- 未做批量并发，5 份需依次上传

## 技术栈

Python / Streamlit / pdfplumber / DeepSeek API（OpenAI SDK 兼容）/ pandas

选用 DeepSeek 的原因：输入价格约为 GPT-4 的 1/40，且完全兼容 OpenAI SDK，更换模型只需修改 base_url 和 model 两个参数，无供应商锁定。

## 本地运行

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
# 在 .env 中填入 DEEPSEEK_API_KEY
streamlit run app.py
```
